# Politique de confidentialité de Ma Tirelire (Harçlıklarım)

Version 2 · 26 octobre 2026 · [Türkçe](https://github.com/yasincirali/piggy-crew/blob/main/legal/gizlilik.md) · [English](https://github.com/yasincirali/piggy-crew/blob/main/legal/privacy.md) · [Deutsch](https://github.com/yasincirali/piggy-crew/blob/main/legal/datenschutz.md) · [Español](https://github.com/yasincirali/piggy-crew/blob/main/legal/privacidad.md) · [Français](https://github.com/yasincirali/piggy-crew/blob/main/legal/confidentialite.md) · [Português](https://github.com/yasincirali/piggy-crew/blob/main/legal/privacidade.md)

Ma Tirelire est une application de tirelire pour les enfants de 7 à 15 ans. Pas de compte, et nous n'avons pas de serveur.

1. **Données collectées :** Aucune. Le prénom de l'enfant, sa tranche d'âge, la devise, les dépôts, les retraits, les autocollants et la progression des leçons restent uniquement sur le téléphone. Rien n'est envoyé ni à nous ni à un tiers. Si la sauvegarde propre du téléphone (iCloud ou Google) est activée, ces données y sont aussi incluses ; toi seul peux voir cette sauvegarde, nous non.
2. **Verrou parental (code PIN) :** Le code n'est pas stocké en clair ; seule une empreinte à sens unique reste sur le téléphone.
3. **Prix :** Pour afficher la valeur du jour des personnages or et devises, l'application demande les prix du jour à un fournisseur public de données de marché. La requête ne contient aucune information sur l'enfant ou le parent ; comme pour toute connexion internet, seule l'adresse internet de l'appareil parvient au fournisseur.
4. **Avis :** « Envoyer un avis » dans le « Coin des parents » ne s'ouvre qu'après saisie du code parental. Le texte est d'abord affiché à l'écran et ne contient ni nom ni montant. Le parent l'envoie avec l'application de son choix (par ex. e-mail).
5. **Publicité, pistage, statistiques, notifications :** Aucun. Pas d'achats intégrés. Aucun code tiers de statistiques ou de publicité.
6. **Suppression :** « Supprimer toutes les données » dans le « Coin des parents », ou la suppression de l'application, efface toutes les données du téléphone.
7. **Contact :** Pour toute question ou demande : https://github.com/yasincirali/piggy-crew/issues

Si cette politique change, le numéro de version augmente et la modification est décrite sur cette page.
