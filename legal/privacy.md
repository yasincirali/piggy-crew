# Pocket Money (Harçlıklarım) Privacy Policy

Version 2 · 26 October 2026 · [Türkçe](https://github.com/yasincirali/piggy-crew/blob/main/legal/gizlilik.md) · [English](https://github.com/yasincirali/piggy-crew/blob/main/legal/privacy.md) · [Deutsch](https://github.com/yasincirali/piggy-crew/blob/main/legal/datenschutz.md) · [Español](https://github.com/yasincirali/piggy-crew/blob/main/legal/privacidad.md) · [Français](https://github.com/yasincirali/piggy-crew/blob/main/legal/confidentialite.md) · [Português](https://github.com/yasincirali/piggy-crew/blob/main/legal/privacidade.md)

Pocket Money is a piggy bank app for children aged 7–15. There is no account and we run no server.

1. **Data we collect:** None. The child's first name, age group, currency, savings entries, withdrawals, stickers and lesson progress are stored only on the phone. Nothing is sent to us or to any third party. If the phone's own backup (iCloud or Google) is turned on, this data is included in that backup; only you can see that backup, we cannot.
2. **Parent lock (PIN):** The PIN is not stored as plain text; only a one-way hash stays on the phone.
3. **Prices:** To show today's value of the gold and currency characters, the app requests the day's prices from a public market data provider. The request carries no information about the child or the parent; as with any internet connection, only the device's internet address reaches the provider.
4. **Feedback:** "Send feedback" in "Parents' corner" opens only after the parent PIN is entered. The text is shown on screen first and contains no name or amounts. The parent sends it with an app of their choice (e.g. email).
5. **Ads, tracking, analytics, notifications:** None. No in-app purchases. No third-party analytics or advertising code.
6. **Deletion:** "Delete all data" in "Parents' corner", or deleting the app, removes all data from the phone.
7. **Contact:** For questions and requests: https://github.com/yasincirali/piggy-crew/issues

If this policy changes, the version number goes up and the change is described on this page.
